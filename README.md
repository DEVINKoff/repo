# BlendPaint — «Procreate для Blender» на iPad

Два компонента:

| Папка | Что это |
|---|---|
| `blender_addon/blendpaint_bridge` | Аддон Blender (сервер на ПК): отдаёт меш, все UV, текстуру и описание шейдера, принимает нарисованные пиксели и пишет их в картинку в реальном времени |
| `ios/` | Приложение для iPad (SwiftUI + Metal, iPadOS 26, Liquid Glass) |
| `.github/workflows/build-ipa.yml` | Сборка неподписанного `.ipa` на GitHub Actions — Mac не нужен |

---

## 1. Blender

1. Заархивируй папку `blender_addon/blendpaint_bridge` в zip (или возьми готовый `blendpaint_bridge.zip`).
2. Blender → *Edit → Preferences → Add-ons → Install from Disk…* → выбери zip → включи аддон.
   Работает на 4.2+ как extension и на 3.6–4.1 как обычный аддон.
3. Сервер стартует сам (порт **47800**). Windows спросит про брандмауэр — разреши для **частных сетей**.
4. N-панель → вкладка **BlendPaint** (есть и в Shader Editor, и в 3D View): там IP компьютера, статус iPad, кнопки.

**Как выбрать что рисовать:** выдели меш → в Shader Editor кликни по ноде *Image Texture*.
С включённым **Follow selection** выбор сразу улетает на iPad; иначе жми **Send to iPad**.
Нет текстуры? Кнопка **New Paint Texture** создаст картинку + ноду и подключит в Base Color.

Обновление картинки в Blender адаптивное: для 4K одна запись пикселей занимает ~0.1–0.2 с, поэтому аддон сам снижает частоту, чтобы Blender не подвисал (минимальный интервал — в настройках аддона).

## 2. Сборка iPad-приложения без Mac

1. Залей эту папку в репозиторий GitHub (можно приватный).
2. *Actions* → **Build BlendPaint** → *Run workflow* (или просто push в `main`).
3. Через ~5–8 минут в артефактах будут `BlendPaint-unsigned-ipa` и `blendpaint_bridge-addon`.
4. Ставь `.ipa` своим обычным способом сайдлоада (Sideloadly / AltStore / свой сертификат) — он переподпишет приложение.

Требуется iPadOS 26 (Liquid Glass). iPad Air M1 поддерживается.
Если сборка упадёт — в артефакте `build-log` полный лог `xcodebuild`.

## 3. Работа в приложении

- Первый запуск: кнопка «Подключиться» → «Найти» (сканирует локальную сеть) или введи IP вручную. iOS спросит разрешение на локальную сеть — разреши.
- Режимы: **2D** (текстура + UV-сетка), **3D** (рисование прямо по модели), **2D + 3D** (сплит, разделитель тянется).
- Рисование в 3D — проекционное: штрих ложится по экрану, переводится в UV, учитывает перекрытие (не красит сквозь меш) и швы UV (дилатация на 2 px).
- Несколько UV: меню UV внизу. По умолчанию берётся UV из ноды *UV Map*, подключённой к картинке, иначе активная для рендера.
- Превью шейдера: Principled BSDF (Base Color, Metallic, Roughness, Normal Map, Emission, Alpha), Separate Color (ORM-текстуры), Mix, Normal Map, Diffuse/Glossy/Emission. Остальные текстуры материала тоже приходят. Меняешь материал в Blender — превью обновляется само.
- Слои: до ~16 штук на 4K (зависит от памяти), 14 режимов наложения, непрозрачность, защита прозрачности, дублирование, объединение вниз, заливка, очистка, сведение. Нижний слой — исходная текстура из Blender.
- Кисти: 15 пресетов (карандаши, тушь, маркер, плоская, аэрографы, спрей, уголь, гранж, царапины…), полный редактор: давление/наклон Pencil, StreamLine, интервал, зерно, разброс, форма кончика, угол по штриху/азимуту Pencil. Отдельная кисть для ластика.
- Undo/redo пиксельный (по тайлам 256×256), лимит ~700 МБ истории.
- Слои сохраняются на iPad для каждой текстуры (`Файлы → На iPad → BlendPaint → Projects`) и предлагаются к восстановлению при повторном открытии.
- Экспорт сведённой текстуры в PNG, «Сохранить изображение в Blender» (save или pack).

**Жесты:** 2 пальца — отменить, 3 — повторить, 4 — скрыть интерфейс, удержание пальцем — пипетка, щипок/поворот — масштаб и вращение холста (поворот прилипает к 90°), в 3D один палец — орбита, два — сдвиг и зум. Двойной тап по Apple Pencil 2 — как в системных настройках iPad (по умолчанию ластик ↔ кисть). Рисование пальцем включается в настройках.

## Ограничения v1

- UDIM-тайлы не поддерживаются; float/EXR-картинки редактируются как 8-бит.
- Нет инструмента «Палец/размазывание» и выделений/трансформа.
- Превью — аппроксимация EEVEE (GGX + 2 источника + небо), а не рендер Blender.
- Связь только в локальной сети, без шифрования.

## Протокол

TCP, кадры `u32 header_len | u32 payload_len | JSON | bytes` (big-endian).
iPad → `hello`, `request_session`, `tiles` (прямоугольники RGBA8, top-left, raw deflate), `save_image`.
Blender → `hello`, `session` (меш: позиции, нормали, все UV, рёбра полигонов, индексы; картинка; доп. текстуры; описание материала), `material`, `status`.
